# flair
FLAIR (Full-Length Alternative Isoform analysis of RNA) builds transcripts from long reads aligned to a genome, counts them in each sample, and tests expression, isoform usage and splicing between conditions. It is used with nanopore cDNA, nanopore direct RNA and PacBio reads.

## FLAIR Announce Mailing list
**If you are using FLAIR, please subscribe to the FLAIR mailing list:**

<https://groups.google.com/a/ucsc.edu/g/flair-announce-group>

This list is read only and low volume, with announcements of new FLAIR releases,
publications and other information for users.

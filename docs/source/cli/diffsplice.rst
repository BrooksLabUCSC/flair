.. rubric:: options

.. option:: -t THREADS, --threads THREADS

   number of threads for parallel DRIMSeq (default: 4)

.. option:: --test

   run DRIMSeq statistical testing

.. option:: --min_samps_gene_expr MIN_SAMPS_GENE_EXPR

   DRIMSeq dmFilter min_samps_gene_expr: minimum number of samples that have coverage over an AS event inclusion/exclusion; events with too few samples are filtered out and not tested (default: 6)

.. option:: --min_samps_feature_expr MIN_SAMPS_FEATURE_EXPR

   DRIMSeq dmFilter min_samps_feature_expr: minimum number of samples expressing the inclusion of an AS event; events with too few samples are filtered out and not tested (default: 3)

.. option:: --min_gene_expr MIN_GENE_EXPR

   DRIMSeq dmFilter min_gene_expr: minimum number of reads covering an AS event inclusion/exclusion; events with too few reads are filtered out and not tested (default: 15)

.. option:: --min_feature_expr MIN_FEATURE_EXPR

   DRIMSeq dmFilter min_feature_expr: minimum number of reads covering an AS event inclusion; events with too few reads are filtered out and not tested (default: 5)

.. option:: --batch

   with --test, DRIMSeq will perform batch correction

.. option:: --condition_a CONDITION_A

   implies --test. The reference condition, as named in the counts matrix columns; the comparison is --condition_b against this. With neither this nor --condition_b given, the two conditions are taken in sorted order

.. option:: --condition_b CONDITION_B

   the condition compared against --condition_a

.. option:: --overwrite_output

   overwrite files in an existing output directory

.. rubric:: required named arguments

.. option:: --isoform_bed ISOFORM_BED

   isoforms in bed format

.. option:: --counts_matrix COUNTS_MATRIX

   tab-delimited isoform count matrix from flair quantify

.. option:: -o OUTPUT, --output OUTPUT

   output directory for tables and plots

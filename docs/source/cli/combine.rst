.. program:: flair combine

.. code-block:: text

   usage: flair combine [-h]
                        (--manifest MANIFEST | --prefixes PREFIXES | --isoform_beds ISOFORM_BEDS)
                        -g GENOME [-o OUTPUT] [--end_window END_WINDOW]
                        [--min_percent_usage MIN_PERCENT_USAGE]
                        [--remove_single_exon] [--max_ends MAX_ENDS]
                        [--min_reads MIN_READS]

.. rubric:: options

.. option:: --manifest MANIFEST

   path to manifest file that has a list of flair bed files paths, eg path/to/isoforms.bed

.. option:: --prefixes PREFIXES

   comma separated list of file prefixes to combine, assuming command is being run in folder that contains prefix.isoform.bed

.. option:: --isoform_beds ISOFORM_BEDS

   comma separated list of paths to flair bed files to combine

.. option:: -g GENOME, --genome GENOME

   genome fasta, required to generate an isoform fasta file and/or a bigbed file

.. option:: -o OUTPUT, --output OUTPUT

   prefix for output file (default: flair.combined.isoforms)

.. option:: --end_window END_WINDOW

   window, in bases, for comparing ends of isoforms with the same intron chain (default: 200)

.. option:: --min_percent_usage MIN_PERCENT_USAGE

   minimum percent usage required in one sample to keep isoform in combined transcriptome (default: 5)

.. option:: --remove_single_exon

   remove all single exon isoforms

.. option:: --max_ends MAX_ENDS

   maximum number of TSS/TES picked per isoform; make higher for more precise end detection. If max_ends is 1, all isoforms/read support for a splice junction chain will be condensed into one isoform. max_ends > 1 introduces greater stringency for assigning og to new isoforms, more read support may be dropped (default: 1)

.. option:: --min_reads MIN_READS

   min reads from all samples to call isoform (default: 3)

.. rubric:: options

.. option:: -o OUTPUT, --output OUTPUT

   output file name base (default: flair)

.. option:: -t THREADS, --threads THREADS

   number of threads to run with (default: 12)

.. option:: --annot_basic ANNOT_BASIC

   GTF annotation file of full-length transcripts, such as GENCODE basic, whose first and last splice sites mark alternative first and last exons. A comprehensive annotation includes truncated transcripts, whose ends are not real first and last exons

.. option:: --junction_tab JUNCTION_TAB

   short-read junctions in SJ.out.tab format. Use this option if you aligned your short-reads with STAR, STAR will automatically output this file

.. option:: --junction_bed JUNCTION_BED

   short-read junctions in bed format (can be generated from long-read alignment with intron-prospector)

.. option:: --junction_support JUNCTION_SUPPORT

   if providing short-read junctions, minimum junction support required to keep junction. If your junctions file is in bed format, the score field will be used for read support (default: 2)

.. option:: --ss_window SS_WINDOW

   window size for correcting splice sites (default: 10)

.. option:: --region_bed REGION_BED

   bed file of the regions to report events in, such as the genes of interest; if not specified, all chromosomes are used. Reads overlapping a region are corrected over their whole length, and the events reported are those inside a region: all their junctions and exons, or, for the start, end, first and last exon events, which count all of a gene's reads, all its annotated junctions

.. option:: --feature_support FEATURE_SUPPORT

   minimum number of reads of a junction, splice site or end of an event in some sample (default: 2)

.. option:: --event_support EVENT_SUPPORT

   minimum number of reads of an event in a sample for its PSI to be calculated (default: 20)

.. option:: --event_frac_of_tot EVENT_FRAC_OF_TOT

   minimum (total reads in splicing event)/(total coverage over locus) to call event (default: 0.1)

.. option:: --junc_frac_of_event JUNC_FRAC_OF_EVENT

   minimum (reads with junction)/(total reads in splicing event). Set to 0 for max recall (default: 0.02)

.. option:: --quality QUALITY

   minimum mapping quality of genomic alignments (default: 1)

.. option:: --trust_strand

   trust the stranding of the input reads and do not attempt strand correction: reads keep the strand of their alignment, and spliced reads are corrected only with splice junctions on that strand, and are only assigned to transcripts on that strand

.. option:: --trust_junctions

   trust the strand of every input splice junction for read correction, without checking splice motifs. By default, an unannotated junction without a GT-AG motif, such as GC-AG or AT-AC, is only weak evidence of strand: a read stranded only by such junctions gets its strand from gene identification, or is dropped

.. option:: --keep_supplementary

   keep supplementary alignments

.. option:: --no_align_to_annot

   skip the initial alignment to the annotated sequences and correct reads only from the genomic alignment. Slightly faster but less accurate when the annotation is good

.. option:: --output_read_ends

   write OUTPUT.spliceevents.readends.bed, the corrected ends of the reads

.. option:: --keep_intermediate

   keep intermediate and temporary files for debugging

.. rubric:: required named arguments

.. option:: -m MANIFEST, --manifest MANIFEST

   tab-separated manifest of sample name and path to its sorted and indexed bam file aligned to the genome, a line per sample

.. option:: -g GENOME, --genome GENOME

   FastA of reference genome, can be minimap2 indexed

.. option:: -f GTF, --gtf GTF

   GTF annotation file, used for correcting reads and assigning them to genes

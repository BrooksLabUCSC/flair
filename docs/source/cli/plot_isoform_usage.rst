   usage: plot_isoform_usage [-h] [-o O] [--min_reads MIN_READS] [-v VCF]

                             isoforms counts_matrix gene_name

.. rubric:: positional arguments

.. option:: isoforms

   isoforms in bed format

.. option:: counts_matrix

   isoform counts

.. option:: gene_name

   Name of gene, must correspond with the gene names in the isoform and counts matrix files

.. rubric:: options

.. option:: -o O

   prefix used for output files (default=gene_name)

.. option:: --min_reads MIN_READS

   minimum number of total supporting reads for an isoform to be visualized (default=6)

.. option:: -v VCF, --vcf VCF

   VCF containing the isoform names that include each variant in the last sample column

.. option:: --palette PALETTE

   provide a palette file if you would like to visualize more than 7 isoforms at once or change the palette used. each line contains a hex color for each isoform

.. program:: bed_to_gtf

.. code-block:: text

   usage: bed_to_gtf [-h] [--force] [--no_cds] [--is_flair_bed] [--log-stderr]
                     [--log-level LOG_LEVEL] [--log-conf LOG_CONF] [--log-debug]
                     inputfile

.. rubric:: positional arguments

.. option:: inputfile

   isoforms in bed format

.. rubric:: options

.. option:: --force

   convert a bed of no gene ids, one not from flair, using each isoform name as both its transcript and gene id

.. option:: --no_cds

   do not copy the CDS from the bed file (thickstart and thickend) to the gtf

.. option:: --is_flair_bed

   the input is a bed12+ file generated by flair; its extra columns are processed and put as attributes in the gtf

.. option:: --log-stderr

   also log to stderr, even when logging to syslog

.. option:: --log-level LOG_LEVEL

   Set level to integer or case-insensitive symbolic value, one of: CRITICAL, FATAL, ERROR, WARN, WARNING, INFO, DEBUG, NOTSET

.. option:: --log-conf LOG_CONF

   Python logging configuration file, see logging.config.fileConfig()

.. option:: --log-debug

   short-cut that sets --log-stderr and --log-level=DEBUG

.. program:: flair diffexp

.. code-block:: text

   usage: flair diffexp [-h] --counts_matrix COUNTS_MATRIX -o OUTPUT [-t THREADS]
                        [--min_expression MIN_EXPRESSION]
                        [--condition_a CONDITION_A] [--condition_b CONDITION_B]
                        [--temp_dir TEMP_DIR] [--keep_intermediate]

.. rubric:: options

.. option:: -t, --threads THREADS

   number of threads for parallel DRIMSeq (default: 12)

.. option:: --min_expression MIN_EXPRESSION

   read count expression threshold: a gene or isoform is tested when the reads of at least one condition, summed over its samples, reach this many, and is left out when both conditions have fewer (default: 10)

.. option:: --condition_a CONDITION_A

   the reference condition, as named in the counts matrix columns; fold changes are reported for --condition_b relative to this. With neither this nor --condition_b given, the two conditions are taken in sorted order

.. option:: --condition_b CONDITION_B

   the condition compared against --condition_a

.. option:: --temp_dir TEMP_DIR

   directory for temporary files; each run makes its own directory, named for the output, in it (default: $TMPDIR or the system temporary directory)

.. option:: --keep_intermediate

   keep the run's own directory, which contains the tables before filtering and the R scripts' diagnostics, and whose path the run reports

.. rubric:: required named arguments

.. option:: --counts_matrix COUNTS_MATRIX

   tab-delimited isoform count matrix from flair quantify, or the counts of flair spliceevents (OUTPUT.spliceevents.counts.tsv), whose usage only is tested. Conditions and batches are read from the sample info TSV beside it

.. option:: -o, --output OUTPUT

   output file name base: each table and plot is written as <output>.<name>, as every other subcommand writes its outputs

.. program:: flair alleles

.. code-block:: text

   usage: flair alleles [-h] --tumor_bam TUMOR_BAM [--normal_bam NORMAL_BAM]
                        --vcf VCF [--normal_vcf NORMAL_VCF] -g GENOME [-o OUTPUT]
                        [-f GTF] [--isoform_bed ISOFORM_BED]
                        [--frac_support FRAC_SUPPORT]
                        [--read_support READ_SUPPORT] [--annotate_bams]
                        [--generate_map]

.. rubric:: options

.. option:: --tumor_bam TUMOR_BAM

   bam file; this is the primary bam input

.. option:: --normal_bam NORMAL_BAM

   optional normal bam file, used to call variants as somatic or not

.. option:: --vcf VCF

   vcf file; a single vcf may be given even when both normal and tumor bams are input

.. option:: --normal_vcf NORMAL_VCF

   normal vcf file, optional even when providing a normal bam

.. option:: -g GENOME, --genome GENOME

   FastA of reference genome

.. option:: -o OUTPUT, --output OUTPUT

   prefix for output files (default: flair)

.. option:: -f GTF, --gtf GTF

   GTF annotation file; either this or --isoform_bed must be provided

.. option:: --isoform_bed ISOFORM_BED

   FLAIR isoform bed file, can be used as primary or supplementary annotation

.. option:: --frac_support FRAC_SUPPORT

   fraction of reads required to call allele, not recommended to change (default: 0.05)

.. option:: --read_support READ_SUPPORT

   number of reads required to call allele (default: 3)

.. option:: --annotate_bams

   label reads in bam files with HP tags for allele groups

.. option:: --generate_map

   output read map of allele groups to read names

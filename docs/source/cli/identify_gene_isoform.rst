.. option:: --proportion PROPORTION_ANNOTATED_COVERED

.. option:: --annotation_reliant

   name all isoforms with -* starting with -0

.. option:: --gene_only

   only append gene name to read name

.. option:: --field_name FIELD_NAME

   field name to use for gene id, e.g. gene_type or gene_name (default: gene_id)

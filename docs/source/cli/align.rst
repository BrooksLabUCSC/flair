.. program:: flair align

.. code-block:: text

   usage: flair align [-h] -r READS [READS ...] (-g GENOME | --mm_index MM_INDEX)
                      [-o OUTPUT] [-t THREADS] [--junction_bed JUNCTION_BED]
                      [--native_rna] [--quality QUALITY]
                      [--filter_type {keepsup,removesup,separate}]
                      [--min_fragment_size MIN_FRAGMENT_SIZE]
                      [--max_intron_len MAX_INTRON_LEN]

.. rubric:: options

.. option:: -g GENOME, --genome GENOME

   FASTA of reference genome, can be minimap2 indexed

.. option:: --mm_index MM_INDEX

   minimap2 index .mmi file

.. option:: -o OUTPUT, --output OUTPUT

   output file name base (default: flair.aligned)

.. option:: -t THREADS, --threads THREADS

   minimap2 number of threads (default: 4)

.. option:: --junction_bed JUNCTION_BED

   annotated isoforms/junctions bed file for splice site-guided minimap2 genomic alignment

.. option:: --native_rna

   use native-RNA specific alignment parameters for minimap2

.. option:: --quality QUALITY

   minimum MAPQ of read alignment to the genome (default: 0)

.. option:: --filter_type {keepsup,removesup,separate}

   method of filtering chimeric alignments (potential fusion reads); separate is required for downstream work with fusions, keepsup keeps supplementary alignments for isoform detection and does not allow gene fusion detection (default: removesup)

.. option:: --min_fragment_size MIN_FRAGMENT_SIZE

   minimum size of alignment kept, used in minimap -s. More important when doing downstream fusion detection (default: 80)

.. option:: --max_intron_len MAX_INTRON_LEN

   maximum intron length in genomic alignment. Longer can help recover more novel isoforms with long introns (default: 200k)

.. rubric:: required named arguments

.. option:: -r READS [READS ...], --reads READS [READS ...]

   FASTA/FASTQ file(s) of raw reads, either space or comma separated

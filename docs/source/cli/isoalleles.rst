.. rubric:: options

.. option:: --allele_vcf ALLELE_VCF

   vcf file from flair alleles

.. option:: --allele_read_map ALLELE_READ_MAP

   tumor read map file from flair alleles

.. option:: --allele_read_map_normal ALLELE_READ_MAP_NORMAL

   optional normal read map file from flair alleles

.. option:: -g GENOME, --genome GENOME

   genome fasta file (used for making big bed)

.. option:: -o OUTPUT, --output OUTPUT

   prefix for output files (default: flair)

.. option:: --isoform_bed ISOFORM_BED

   isoform bed generated by FLAIR transcriptome

.. option:: --iso_read_map ISO_READ_MAP

   read map for tumor/single sample by FLAIR transcriptome or flair quantify

.. option:: --iso_read_map_normal ISO_READ_MAP_NORMAL

   optional read map for the normal sample by FLAIR transcriptome or flair quantify

.. option:: --tumor_bam TUMOR_BAM

   optional tumor bam; only provide to output reads labeled with iso-allele groups, mostly for debugging

.. option:: --normal_bam NORMAL_BAM

   optional normal bam; only provide to output reads labeled with iso-allele groups, mostly for debugging

.. option:: --generate_map

   output read map of allele-isoform groups to read names

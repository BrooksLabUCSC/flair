.. rubric:: options

.. option:: --germline_vcf GERMLINE_VCF

   the germline variant calls, of the sample, or in a pair the normal, when --phased_vcf holds only some of them, as when only hets were phased: every passing call is a germline variant, phased by --phased_vcf. bgzipped and indexed (default: --phased_vcf)

.. option:: --sample_name SAMPLE_NAME

   the name of --bam's sample in the outputs (default: its file name)

.. option:: --carrier_min CARRIER_MIN

   an unphased germline het is put on the haplotype holding at least this share of an isoform's tagged reads carrying it (default: 0.9)

.. option:: --min_tagged MIN_TAGGED

   the tagged reads carrying an unphased germline het needed to place it (default: 10)

.. option:: -o OUTPUT, --output OUTPUT

   output file name base (default: flair)

.. option:: -t THREADS, --threads THREADS

   batches of genes processed at once (default: 4)

.. option:: --generate_map

   write each sample's reads by isoform and group, <output>.isoalleles.<sample>.read.map.tsv

.. option:: --label_bams

   write each sample's assigned reads with their isoform and group in the IA tag, <output>.isoalleles.<sample>.bam (in IGV, group by tag IA)

.. option:: --temp_dir TEMP_DIR

   directory for temporary files, in a directory of the run's own (default: $TMPDIR)

.. rubric:: required named arguments

.. option:: --isoform_bed ISOFORM_BED

   the isoforms, the flair isoform bed the read maps were made with by flair quantify; its CDS gives each isoform's start codon. Fusion isoforms are left out

.. option:: -g GENOME, --genome GENOME

   FASTA of the genome, indexed with samtools faidx

.. option:: --bam BAM

   the sample's (in a pair, the tumor's) reads aligned to the genome, sorted and indexed, haplotagged (HP and PS tags) by the phasing of --phased_vcf

.. option:: --read_map READ_MAP

   the read map flair quantify --generate_map wrote for --bam's sample, <output>.<sample>.read.map.tsv, plain, bgzip or gzip

.. option:: --phased_vcf PHASED_VCF

   the germline variants, phased: the VCF the phasing tool wrote and haplotagged --bam with, the sample's own, or in a pair the normal's. bgzipped and indexed

.. rubric:: tumor and normal pair

.. option:: --normal_bam NORMAL_BAM

   the normal's reads, haplotagged by the same phasing as --bam; makes the run a pair, whose tumor reads, of --bam, are grouped by somatic variants too

.. option:: --normal_read_map NORMAL_READ_MAP

   the read map of --normal_bam's sample, from the same flair quantify

.. option:: --normal_name NORMAL_NAME

   the name of the normal in the outputs (default: its file name)

.. option:: --tumor_vcf TUMOR_VCF

   the tumor's variant calls: its passing calls that --phased_vcf, the normal's, does not call are somatic if at least --min_normal_depth normal reads inform the site, and are otherwise left out, in excluded.tsv. bgzipped and indexed

.. option:: --somatic_vcf SOMATIC_VCF

   the somatic variants, every passing call of a somatic caller's VCF (such as ClairS or DeepSomatic), as it calls them. bgzipped and indexed

.. option:: --variant VARIANT

   a somatic variant, CHROM:POS:REF>ALT, or CHROM:POS for every alt the VCFs have there; may be given more than once. Only the variants given are somatic, whatever the VCFs call, as for a known driver the normal calls because tumor cells are in it

.. option:: --min_normal_depth MIN_NORMAL_DEPTH

   with --tumor_vcf, the normal reads informing a site for a tumor-only call there to be somatic (default: 10)

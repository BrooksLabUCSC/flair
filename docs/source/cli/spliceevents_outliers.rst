.. program:: spliceevents_outliers

.. code-block:: text

   usage: spliceevents_outliers [-h] -i INPUT -o OUTPUT [--psi {junc,tot}]
                                [--event_support EVENT_SUPPORT] [--log-stderr]
                                [--log-level LOG_LEVEL] [--log-conf LOG_CONF]
                                [--log-debug]

.. rubric:: options

.. option:: -i, --input INPUT

   output prefix of flair spliceevents: reads its OUTPUT.spliceevents.counts.tsv and OUTPUT.spliceevents.totals.tsv

.. option:: -o, --output OUTPUT

   output prefix: writes OUTPUT.spliceevents.outliers.tsv, every outlier, and OUTPUT.spliceevents.outliers.filtered.tsv, those more than 6 deviations from the median and not explained by a simpler event, without starts and ends (tss, tts), whose outliers are mostly false positives. An event needs 5 samples with a PSI for an outlier of it to be called, so with fewer samples both files contain only their header

.. option:: --psi {junc,tot}

   the PSI to call outliers of: 'junc', of the event's reads (PSIjunc), more sensitive, or 'tot', of the reads covering its locus (PSItot), for strong overall events (default: junc)

.. option:: --event_support EVENT_SUPPORT

   minimum reads of a sample for its PSI of an event to be used, as flair spliceevents --event_support (default: 20)

.. option:: --log-stderr

   also log to stderr, even when logging to syslog

.. option:: --log-level LOG_LEVEL

   Set level to integer or case-insensitive symbolic value, one of: CRITICAL, FATAL, ERROR, WARN, WARNING, INFO, DEBUG, NOTSET

.. option:: --log-conf LOG_CONF

   Python logging configuration file, see logging.config.fileConfig()

.. option:: --log-debug

   short-cut that sets --log-stderr and --log-level=DEBUG

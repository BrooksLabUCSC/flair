.. program:: spliceevents_outliers

.. code-block:: text

   usage: spliceevents_outliers [-h] -i INPUT -o OUTPUT [--psi {junc,tot}]
                                [--event_support EVENT_SUPPORT]

.. rubric:: options

.. option:: -i INPUT, --input INPUT

   output prefix of flair spliceevents: reads its OUTPUT.spliceevents.counts.tsv and OUTPUT.spliceevents.totals.tsv

.. option:: -o OUTPUT, --output OUTPUT

   output prefix: writes OUTPUT.spliceevents.outliers.tsv, every outlier, and OUTPUT.spliceevents.outliers.filtered.tsv, those more than 6 deviations from the median and not explained by a simpler event

.. option:: --psi {junc,tot}

   the PSI to call outliers of: 'junc', of the event's reads (PSIjunc), more sensitive, or 'tot', of the reads covering its locus (PSItot), for strong overall events (default: junc)

.. option:: --event_support EVENT_SUPPORT

   minimum reads of a sample for its PSI of an event to be used, as flair spliceevents --event_support (default: 20)

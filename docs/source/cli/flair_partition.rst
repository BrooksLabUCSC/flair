.. rubric:: positional arguments

.. option:: ranges_bed

   Output ranges BED file, compressed if its name ends in .gz. It is a BED4 with the number of input items in each partition as a fifth column

.. rubric:: options

.. option:: --min_partition_items MIN_PARTITION_ITEMS

   Minimum number of input items in a partition

.. option:: --part_merge_dist PART_MERGE_DIST

   Combine adjacent non-overlapping partitions separated by this distance

.. option:: --threads THREADS

   Number of cores for converting inputs, a BAM by chromosome, and sorting (default: 1)

.. option:: --bed BED

   Input BED file, may be compressed. May be repeated

.. option:: --bam BAM

   Input SAM/BAM file. May be repeated

.. option:: --gtf GTF

   Input GTF file. May be repeated

.. option:: --region_bed REGION_BED

   BED of regions to restrict the partitions to, such as the genes of interest. Only input items overlapping a region are read, an indexed BAM by random access, and the regions are then grown over the items reaching them until they stop growing, so each partition contains every item that a partition of the whole input would. Not used with --min_partition_items

.. option:: --region REGION

   region to restrict the partitions to. The notes under --region_bed apply to it as well. A region is either one-based and closed, chr1:1,000-2,000, or zero-based and half-open, chr1 999 2000, as a BED line. May be repeated, and may be used with --region_bed, whose regions are added to it

.. option:: --log-stderr

   also log to stderr, even when logging to syslog

.. option:: --log-level LOG_LEVEL

   Set level to integer or case-insensitive symbolic value, one of: CRITICAL, FATAL, ERROR, WARN, WARNING, INFO, DEBUG, NOTSET

.. option:: --log-conf LOG_CONF

   Python logging configuration file, see logging.config.fileConfig()

.. option:: --log-debug

   short-cut that that sets --log-stderr and --log-level=DEBUG

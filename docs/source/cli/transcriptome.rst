.. rubric:: options

.. option:: -o OUTPUT, --output OUTPUT

   output file name base for FLAIR isoforms, defaults to --sample_name

.. option:: -f ANNOT_GTF, --gtf ANNOT_GTF

   GTF annotation file, used for identifying annotated isoforms

.. option:: --junction_tab JUNCTION_TAB

   short-read junctions in SJ.out.tab format. Use this option if you aligned your short-reads with STAR, STAR will automatically output this file

.. option:: --junction_bed JUNCTION_BED

   short-read junctions in bed format (can be generated from long-read alignment with intron-prospector)

.. option:: --junction_support JUNCTION_SUPPORT

   if providing short-read junctions, minimum junction support required to keep junction. If your junctions file is in bed format, the score field will be used for read support (default: 2)

.. option:: --ss_window SS_WINDOW

   window size for correcting splice sites (default: 10)

.. option:: --end_window END_WINDOW

   window size for comparing TSS/TES (default: 100)

.. option:: --sjc_support SJC_SUPPORT

   minimum number of supporting reads for a spliced isoform (default: 1)

.. option:: --single_exon_support SINGLE_EXON_SUPPORT

   minimum number of supporting reads for a single exon isoform (default: 3)

.. option:: --frac_support FRAC_SUPPORT

   minimum fraction of gene locus support for isoform to be called; only isoforms that make up more than this fraction of the gene locus are reported. Set to 0 for max recall (default: 0.05)

.. option:: --directRNA

   input is directRNA - this sets trust_strand to True, also doesn't allow large deletions in UTRs (an artifact of cDNA amplification)

.. option:: --trust_strand

   trust the stranding of the input reads and do not attempt strand correction: reads keep the strand of their alignment, and spliced reads are corrected only with splice junctions on that strand, and are only assigned to transcripts on that strand

.. option:: --trust_junctions

   trust the strand of every input splice junction for read correction, without checking splice motifs. By default, an unannotated junction without a GT-AG motif, such as GC-AG or AT-AC, is only weak evidence of strand: a read stranded only by such junctions gets its strand from gene identification, or is dropped

.. option:: --trust_ends

   trust the ends of the input reads: a more stringent way of requiring read ends to match the ends of transcript models

.. option:: --no_stringent

   do not require all supporting reads to be full-length, that is aligned to the first and last exons of the transcript. Use this for fragmented libraries, with an understanding that it will impact precision

.. option:: --no_check_splice

   do not enforce accurate alignment around splice sites. Specify this for libraries with high error rates, but it will reduce precision

.. option:: --no_align_to_annot

   skip the initial alignment to the annotated sequences and detect transcripts only from the genomic alignment. Slightly faster but less accurate when the annotation is good

.. option:: --max_ends MAX_ENDS

   maximum number of TSS/TES picked per isoform; make higher for more precise end detection (default: 1)

.. option:: --filter FILTER

   which subset isoforms (a contiguous part of another isoform) to keep. <N>X, such as 10X: a subset isoform is kept if it has more than N times the reads of the isoforms it is a subset of; nosubset: all subset isoforms are removed; comprehensive: all spliced subset isoforms are kept; ginormous: comprehensive, plus single exon subset isoforms (default: nosubset)

.. option:: --keep_supplementary

   keep supplementary alignments when defining isoforms

.. option:: --quality QUALITY

   minimum mapping quality threshold to consider genomic alignments for defining transcripts (default: 1)

.. option:: --allow_paralogs

   NOT IMPLEMENTED: assign reads to multiple paralogs with equivalent alignment. Specifying this is an error rather than a no-op

.. option:: -t THREADS, --threads THREADS

   number of threads to run with, related to --parallel_mode (default: 12)

.. option:: --parallel_mode PARALLEL_MODE

   parallelization mode. auto:1GB is an automatic threshold where, if the file is less than 1GB, parallelization is done by chromosome, and if it is larger, parallelization is done by region of non-overlapping reads. Other modes: bychrom, byregion, auto:xGB; for the auto threshold, the size must be in units of GB (default: auto:1GB)

.. option:: --fusion_breakpoints FUSION_BREAKPOINTS

   for fusion detection only: bed file containing locations of fusion breakpoints on the synthetic genome

.. option:: --temp_dir TEMP_DIR

   directory for temporary files; each run makes its own directory, named for the output, in it. Many small files are written and removed, so a local disk is much faster than network storage (default: $TMPDIR or the system temporary directory)

.. option:: --keep_intermediate

   keep intermediate and temporary files for debugging, in the run's directory in --temp_dir, which must be given. Intermediate files include the promoter-supported reads file and read assignments to firstpass isoforms

.. option:: --normalize_ends

   normalize transcript ends with similar terminal splice sites. Each spliced junction chain gives a single isoform, with the furthest start and end of its reads, overriding --max_ends

.. option:: --generate_map

   generate a txt file of read-isoform assignments

.. rubric:: required named arguments

.. option:: -b GENOME_ALIGNED_BAM, --genome_aligned_bam GENOME_ALIGNED_BAM

   Sorted and indexed bam file aligned to the genome

.. option:: -g GENOME, --genome GENOME

   FastA of reference genome, can be minimap2 indexed

.. option:: --sample_name SAMPLE_NAME

   name of sample - this will be added as metadata to your output files
